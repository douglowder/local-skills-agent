# Analyze Code Skill

Analyze Python code files and provide insights about structure, complexity, and potential improvements.

## Instructions

When this skill is invoked, you should:

1. Ask the user which Python file they want to analyze (or they may have already specified it)
2. Use the `read_file` tool to read the Python file
3. Analyze the code for:
   - Code structure and organization
   - Function and class definitions
   - Potential improvements or issues
   - Code complexity
   - Documentation quality
4. Provide a clear, structured analysis to the user

## Analysis Areas

- **Structure**: How is the code organized?
- **Functions**: What functions are defined and what do they do?
- **Classes**: What classes exist and their purpose?
- **Imports**: What dependencies are used?
- **Documentation**: Are there docstrings and comments?
- **Best Practices**: Does it follow Python best practices?
- **Suggestions**: What could be improved?
